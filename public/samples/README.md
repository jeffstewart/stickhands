# Drum sample attributions

## muldjord/

One-shot samples extracted from **MuldjordKit** (FreePats version 2020-10-18),
an acoustic drum kit recorded by **Lars Muldjord** (www.muldjord.com,
www.drumgizmo.org), assembled for the FreePats project by roberto@zenvoid.org.

License: Creative Commons Attribution 4.0 International (CC-BY 4.0)
http://creativecommons.org/licenses/by/4.0/

Source: https://freepats.zenvoid.org/Percussion/acoustic-drum-kit.html

Modifications: selected a subset of velocity layers per drum; converted from
FLAC to 16-bit WAV; renamed by lane/velocity-layer.
